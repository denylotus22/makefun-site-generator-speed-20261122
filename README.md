A faster drop-in for make.fun's makefun-site 1.0.0 static site generator: byte-exact builds of every page, index, tag page, report and static file, in less CPU time than the reference. `solve.js` is a dependency-free ES module whose `run(input)` returns the output tree for one generated site; `main.ts` is the harness program that answers every case in `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
